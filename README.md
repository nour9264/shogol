# شغل - منصة العمل الحر الاحترافية

منصة احترافية تربط بين أصحاب المشاريع والمستقلين المحترفين في الوطن العربي.

## المميزات

- 🎯 واجهة مستخدم عصرية ومتجاوبة
- 🌍 دعم كامل للغة العربية (RTL)
- 🔒 نظام أمان متقدم مع JWT
- 💬 محادثات فورية عبر WebSocket
- 📱 تصميم متجاوب يعمل على جميع الأجهزة
- ⚡ أداء سريع باستخدام React + Vite
- 🎨 تصميم احترافي مع Tailwind CSS

## التقنيات المستخدمة

- **React 18** - مكتبة واجهة المستخدم
- **React Router v6** - التنقل بين الصفحات
- **Axios** - إدارة طلبات API
- **SignalR** - المحادثات الفورية
- **React Hook Form** - إدارة النماذج والتحقق
- **Tailwind CSS** - التنسيق والتصميم
- **Vite** - أداة البناء السريعة

## البدء

### المتطلبات

- Node.js (v18 أو أحدث)
- npm أو yarn

### التثبيت

\`\`\`bash
# تثبيت المكتبات
npm install

# تشغيل مخدم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
\`\`\`

## هيكل المشروع

\`\`\`
src/
├── components/       # المكونات القابلة لإعادة الاستخدام
├── pages/           # صفحات التطبيق

├── services/        # خدمات API
├── hooks/           # Custom React Hooks
├── utils/           # دوال مساعدة
├── styles/          # ملفات CSS
└── assets/          # الصور والملفات الثابتة
