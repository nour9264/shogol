# PWA Setup Instructions

## Installation Steps

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Create app icons:**
   You need to create PWA icons in the `public/icons/` directory with the following sizes:
   - icon-72x72.png
   - icon-96x96.png
   - icon-128x128.png
   - icon-144x144.png
   - icon-152x152.png
   - icon-192x192.png
   - icon-384x384.png
   - icon-512x512.png

   **Quick way to generate icons:**
   - Use a tool like [PWA Asset Generator](https://www.pwabuilder.com/imageGenerator)
   - Or use your logo and resize it to all required sizes

3. **Optional: Add screenshots** (for better PWA install prompt):
   - Create `public/screenshots/desktop-1.png` (1280x720)
   - Create `public/screenshots/mobile-1.png` (750x1334)

## What's Been Configured

✅ **PWA Manifest** (`public/manifest.json`)
- App name, description, and branding
- Icon definitions for all sizes
- Display mode set to "standalone" (looks like a native app)
- Theme colors matching your app
- App shortcuts for quick actions

✅ **Service Worker** (auto-generated by next-pwa)
- Offline support
- Smart caching strategies:
  - Google Fonts: Cached for 1 year
  - API calls: Network-first with 5-minute cache
  - Images: Cached for 30 days
  - Static resources: Stale-while-revalidate

✅ **Next.js Configuration** (`next.config.ts`)
- PWA plugin integrated
- Disabled in development (for easier debugging)
- Auto-registration of service worker

✅ **App Layout** (`src/app/layout.tsx`)
- PWA meta tags
- Apple Web App support
- Theme color for status bar
- Open Graph tags for social sharing

## Testing Your PWA

### Development
```bash
npm run dev
```
Note: PWA is disabled in development mode

### Production Build
```bash
npm run build
npm start
```

### Test PWA Features
1. Open your app in Chrome/Edge
2. Look for the install button in the address bar
3. Click "Install" to add to home screen
4. Test offline mode by:
   - Installing the app
   - Turning off your internet
   - Opening the installed app
   - Navigate to previously visited pages (they should load from cache)

## PWA Features Enabled
